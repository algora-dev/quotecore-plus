# Supplier directory and component import

The supplier directory lets you browse component libraries published by approved suppliers, search for specific products, and import components directly into your own library. This means you can build your quote library from real supplier pricing and specifications without manually entering each item.

## Who can use it

All QuoteCore+ users can **browse** the supplier directory and **import** supplier components. You do not need to be a supplier yourself - this is a consumer-facing feature.

## Browsing the directory

1. Go to **Resources** in the main navigation.
2. Click **Supplier Directory**.
3. Browse approved suppliers, or use the search to find suppliers by name, brand, product category, or keyword.
4. Click a supplier to see their published libraries.
5. Click a library to see its components - each shows name, SKU, price, product type, and notes.

Each supplier profile shows:

- Supplier name and description.
- Service areas and roofing types covered.
- Product categories and brands.
- Website link.

## Searching for components

Within a supplier library, you can:

- **Search by text** - component name, SKU, or description.
- **Filter by product category** - e.g. underlay, fixings, flashings.
- **Filter by brand** - e.g. Marley, Colorsteel.

## Importing components

When you find a component you want in your own library:

1. Click **Import** next to the component (or **Import All** for a whole library).
2. The component is copied into your component library with:
   - Name, SKU, price, product type, and notes from the supplier.
   - A reference back to the source supplier component.
   - The source version number (so we can detect updates later).
3. Imported components behave exactly like any other component in your library - edit them, use them in quotes, attach them to roof areas.

### Selective import

You do not have to import an entire library. Pick individual components or select multiple - only the ones you choose are copied.

## Pending update notifications

When a supplier updates a component you have previously imported:

- A **pending updates** banner appears on your Components page.
- The banner shows how many components have updates (added, modified, price changed, or removed).
- Click **Review** to see the changes side by side.
- Choose to **accept** the update (apply the supplier's new version) or **dismiss** it (keep your current version).

You are always in control - supplier updates never auto-overwrite your components.
