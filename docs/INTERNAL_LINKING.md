# Internal Linking Rules

> Reference for all public pages on quote-core.com and quote-core.co.nz.

## Principles

1. Every internal link uses descriptive anchor text that tells the user (and search engine) what the destination page is about.
2. Link only to genuinely useful next steps. Do not force links into pages where they add no value.
3. Avoid repetitive exact-match anchors across many pages. Vary naturally.
4. Never use "click here", "learn more", "read this", or similar generic anchors.
5. Internal links are server-rendered in HTML (not client-only) so search engines can crawl them.

## Linking rules by page type

### Homepage
Links to:
- `/roofing-quoting-software` - "roofing quoting software"
- `/construction-quoting-software` - "construction quoting software"
- `/free-tools` - "free tools"
- `/free-trial` - "start free trial"
- `/#pricing` - "pricing"
- `/suppliers` - "supplier network" or "for suppliers"
- `/services` - "done-for-you quoting service"
- `/company` - "company" or "about QuoteCore+"
- `/about` - "founder story"
- `/blog` - "blog" or "guides"

### Landing pages (roofing / construction)
Links to:
- All relevant feature pages (once built)
- `/#pricing` - "pricing"
- `/free-trial` - "start free trial"
- Relevant calculators
- Relevant blog posts
- Case studies (once built)
- `/services` - "done-for-you quoting service"

### Feature pages
Links to:
- Main landing page (`/roofing-quoting-software` or `/construction-quoting-software`)
- Related feature pages
- `/#pricing` - "pricing"
- `/free-trial` - "start free trial"
- Relevant calculator (e.g., takeoff feature -> roofing calculator)
- Relevant blog post (e.g., smart components -> reusable templates post)

### Blog posts
Links to (at minimum):
- Relevant landing page (`/roofing-quoting-software` or `/construction-quoting-software`)
- Related feature page (if one exists)
- Relevant calculator (if the post discusses a calculation)
- `/free-trial` - "start free trial"
- At least one other related blog post

### Calculator pages
Links to:
- Explanation guide (blog post on the same topic, if one exists)
- Related feature page (if one exists)
- Relevant landing page
- `/free-trial` - "start free trial"
- Related calculator (via "Related Tools" section)

### Company / About pages
Links to:
- `/free-trial` - "start free trial"
- `/blog` - "blog"
- `/#pricing` - "pricing"
- `/contact` - "contact"

### NZ site pages
Same rules as above, but:
- Blog links go to `https://quote-core.com/blog` (marked as external)
- Feature pages (once built on .com) should be linked with external marking until NZ equivalents exist
- App links go to `https://app.quote-core.com` (marked as external)

## Anchor text examples

Good:
- "roof takeoff software"
- "Smart Components"
- "material ordering"
- "roofing calculator"
- "how to price a roofing job"
- "start free trial"
- "compare roofing quoting software"

Bad:
- "click here"
- "learn more"
- "read this"
- "check it out"
- "link"

## Maintenance

- When a new feature page is created, add links to it from relevant blog posts and landing pages.
- When a new blog post is published, add at least 2 internal links from existing pages to it.
- When a new calculator is added, link it from the relevant trade landing page and free tools hub.
- Review internal links quarterly as part of the SEO review cycle.
