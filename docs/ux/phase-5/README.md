# Phase 5 — Unified Document Editors

Implementation candidate · 25 September 2026 · owner preview pending.

Four editor workspaces cover five output formats: Customer Quote, Invoice, Line-by-line Order, and Visual Order with one or two columns. Shared C55/T05 chrome, not a shared business controller. Labour Sheet inherits the quote editor's presentation and keeps its own supplied title/save/tax contract.

Read `INTEGRATION.md`, `PARITY_CHECKLIST.md`, `CAPABILITY_PARITY.csv` and `STATIC_VALIDATION.md`. `SOURCE_BINDING_AUDIT.json` records the source comparisons. `FILE_CHANGES.json` is the explicit implementation file set. `fixtures/` contains labelled, source-derived **non-React** specimens, not screenshots of the running product.
