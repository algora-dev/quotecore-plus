# Visual reference provenance

HTML markup is rendered from QcAppShell, QcNavigation, QcSidebarTab, JobSpacesList, QcIcon, QcButton, QcNotice and QcDialog using a non-React static JSX adapter. Styles are flattened directly from the returned CSS. Data is illustrative. Browser JavaScript demonstrates CSS toggle/filter/dialog behaviour only. This is not a React hydration, Next routing, authentication, RLS, full-list completeness, mutation or canvas test.
