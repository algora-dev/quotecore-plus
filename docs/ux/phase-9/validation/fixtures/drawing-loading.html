Drawing tools and shortcuts
  • Line Tool: Click points to draw. Angles appear automatically after 3rd point.
  • Text Tool: Click to add text labels anywhere on the canvas.
  • Pencil Tool: Freehand draw with 3 thickness options. Drawings are movable and resizable.
  • Select All: Ctrl+A to select and move entire drawing.
  • Sidebar: Click any measurement to highlight it on canvas.
  • Measurements: Appear as Length → Angle → Length → Angle...
  • Toggle Angle: Switch between interior/exterior angles in sidebar.
  • Hide/Show: Toggle visibility of individual measurements.
  • Edit Values: Change any measurement value manually.
  • Auto-Calculate: Use roof pitch calculator for accurate angles.
